# ProShorts Studio (Gemini Edition)

A specialized video editing tool designed for clipping shorts/reels from long-form videos. It features a modern, Gemini-inspired dark UI and a high-performance FFmpeg backend.

![UI Preview](https://via.placeholder.com/800x450?text=App+Screenshot+Placeholder)
## Features
- **Gemini-Themed UI:** Sleek dark mode with gradients and smooth rounded corners.
- **Zoomable Timeline:** Scroll to zoom in/out of the timeline for precise frame-by-frame trimming.
- **Queue System:** Select multiple clips from one video and export them all at once.
- **Smart Export:** - **Match Source:** Preserves original quality and bitrate.
  - **Custom Mode:** Force 1080p/2K resolution and HDR (HEVC) tagging.
- **Auto-FFmpeg Detection:** Automatically finds FFmpeg on your system.

## Requirements
- Python 3.8+
- [FFmpeg](https://ffmpeg.org/download.html) (Must be installed and added to system PATH)
